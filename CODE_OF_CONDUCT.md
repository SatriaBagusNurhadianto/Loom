# Code of Conduct

We want Loom to be a welcoming place to build scientific writing tools. Be considerate, communicate constructively, and respect differences in experience, background, and perspective. Harassment, discrimination, personal attacks, and publishing someone else's private information are not acceptable.

Maintainers may remove content, close discussions, or restrict participation when necessary to keep the community safe. If you need to report a concern privately, ask a maintainer for a private contact through a GitHub issue without including sensitive details. For security vulnerabilities, follow [SECURITY.md](SECURITY.md).
