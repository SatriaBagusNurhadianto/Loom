# Security

Please do not post security vulnerabilities, credentials, private manuscripts, or exploit details in a public issue.

If **Report a vulnerability** is available on the repository's [security advisories page](https://github.com/monabji/loom/security/advisories), use it to contact the maintainers privately. If it is unavailable, open an issue asking for a private security contact without including sensitive details.

Please include the affected version, a minimal synthetic reproduction, the impact, and any mitigation when you submit the private report. Maintainers will review reports and coordinate disclosure as a fix is prepared.
