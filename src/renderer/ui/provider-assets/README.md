# Provider marks

Bundled locally so provider identification works offline. Marks belong to their respective owners and identify the installed agent; they do not imply endorsement of Loom.

- `opencode.svg`: unmodified dark square mark from [OpenCode’s brand assets](https://github.com/anomalyco/opencode/blob/dev/packages/console/app/src/asset/brand/opencode-logo-dark-square.svg), published with the [OpenCode brand resources](https://opencode.ai/brand).
- `ProviderLogo.tsx`: monochrome OpenAI mark from [OpenCode’s provider icon catalog](https://github.com/anomalyco/opencode/blob/dev/packages/ui/src/assets/icons/provider/openai.svg). Used to identify Codex, following [OpenAI’s brand guidelines](https://openai.com/brand/). Its path geometry remains unchanged; the inline SVG inherits the surrounding monochrome text color.

Retrieved 4 November 2026. No remote assets are loaded at runtime.
