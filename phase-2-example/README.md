# Phase 2 example project

This synthetic multi-file project is for exercising Loom's local project workflows. Open this folder with **Open or create project → Open folder**. The root document is `main.tex`; the section path `sections/背景.tex` is intentionally Unicode. `assets/sample.png` is a tiny local image, and `references.bib` is a fictional bibliography entry.

## Try these workflows

1. Search for `baseline-recovery`. Open the result and confirm Loom shows its path, line, and snippet.
2. Create a file such as `notes/extra.tex`, rename or move it, then delete and restore it from **Recover deleted files**.
3. Edit `sections/背景.tex`, save, close the project, and reopen it. Check the active file and caret restoration.
4. With the project open, change one sentence in Loom and save. Then edit a different sentence in the same file using an external editor. Wait for Loom to observe the change and confirm both edits remain.
5. To exercise conflict review, make a local edit to a sentence, then change that same sentence externally before saving the local edit. Review the overlap and choose **Keep local text** or **Use disk version**.
6. Import this folder as a copy to confirm the original folder remains intact.

For recovery experiments, leave Loom's application data in place; it contains local recovery checkpoints. All names and manuscript content here are synthetic.
